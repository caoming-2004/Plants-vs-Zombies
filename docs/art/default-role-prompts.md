# 默认风格角色素材说明

默认皮肤使用经典塔防游戏的植物、僵尸语汇，保持原创简化卡通造型与清晰轮廓。不得将提取参考图描述成可自由再分发素材；现有经典参考帧来源及其非商业声明记录在 `assets/sources.json` 和 `assets/skins/default/provenance.json`。新增坚果墙和火爆辣椒是内置图像生成的原创卡通帧，源表位于 `assets/skins/default/source/`。

素材生成提示：

- 坚果墙：高分辨率透明背景，单体正面偏右的坚果防御植物，稳定椭圆外轮廓；分别表达细微待机、受击裂纹和倒下，不改变角色位置基准。
- 火爆辣椒：高分辨率透明背景，单体红色辣椒植物；分别表达待机、点燃、火焰爆发、受击和消散，火焰朝整行展开。
- 所有关键动作源图为规则 6×4 姿势格；不得跨格裁切，导入器固定脚底线并生成2x帧图集。
