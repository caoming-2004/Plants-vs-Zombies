# US1 原型试玩验证记录

日期：2026-10-25。范围：T001至T027，后续原版美术US2与小狗换肤US3未实施。

## 已实现

独立Python3.12.15 x64环境；pygame-ce2.5.8；PyInstaller6.22.3，确切依赖见requirements.lock.txt。
纯Python模拟、递归只读快照、集中配置、五行九列、两植物一僵尸、12只有限出怪。
阳光收集/产出/到期、种植事务/冷却、同排攻击/啃咬、死亡、铲子、每行一次割草机、
暂停/恢复、胜负、重新开始及返回菜单。鼠标操作，右键/Esc取消，空格暂停，失焦自动暂停。
当前采用程序绘制原型，不声称原版一致；没有小狗皮肤选项。

## 试玩方式

解压dist/PvzMiniGame-windows-x64.zip，打开PvzMiniGame，双击PvzMiniGame.exe。
已有解压目录dist/PvzMiniGame也可以直接试玩，保留_internal与所有资源。
窗口已启动供用户接管；Computer Use已停止，不自动恢复操作。

建议先打开“怎么玩”，再种两株向日葵，持续收集阳光，并按出怪顺序在五行各放一株射手。
验证失败可以重新开始且不影响文件。请重点检查鼠标操作、提示、冷却、暂停、铲除与重开体验。
