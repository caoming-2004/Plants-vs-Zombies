# 005 实机性能验收

## 测量实现

- `tools/benchmark.py --window --scene standard|pressure --seconds 60` 进入真实显示路径；可用 `--plant-skin dogs_photo` 测量照片版。
- 标准负载为5向日葵、5豌豆射手、5僵尸、10投射物、3阳光和5割草机；压力负载为45植物、30僵尸、100投射物、20阳光和5割草机。
- 报告包含平均 FPS、P95 帧间隔、最长连续 >50ms 帧数，以及事件处理、Simulation step、Renderer、窗口缩放合成和 display flip 的分段统计。
- `--input-latency --seconds 60` 需要实际鼠标种植、铲除和收集；每次操作必须由对应游戏事件确认，并在后续 flip 记录可见反馈时间。报告会输出操作数、P95、漏操作及重复事件。
- 默认 SDL dummy 基准保留为诊断用途，不可替代下面的真实显示测量。

## 结果

尚未生成旧版打包基线或新版打包实测数据。发行包构建和真实窗口性能测试未运行；不得据此宣称达到55 FPS、33ms P95 或100ms交互反馈目标。现有更改只完成测量入口和分段统计。
