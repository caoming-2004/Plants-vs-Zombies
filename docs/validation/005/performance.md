# 005 实机性能验收

## 采样路径

- 诊断版发行包通过真实 Windows display driver 打开 1260×720 窗口；固定场景保持显式列出的植物、僵尸、投射物、阳光和割草机数量。每轮连续60秒。
- 报告包含完整帧间隔数组、平均FPS、P95、连续慢帧和事件、Simulation.step、Renderer、窗口缩放合成、display flip、帧率等待分段耗时；报告文件链接见下方。
- `measurement_scope` 为确定性渲染场景加固定负载的 Simulation.step；未计入真实鼠标操作。

## 定位与优化

第一轮打包样本（T024前）标准场景46.85 FPS、P95 31.33ms。窗口缩放阶段平均8.20ms、P95 11.50ms，是当时主要瓶颈。改用快速输出缩放后该轮只有34.45 FPS，故未保留为最终实现。

压力样本进一步显示每帧生成未被使用的 Simulation 完整快照、动画查找反复统计帧时长，以及目标筛选排序都占用额外时间。保留默认 `Simulation.step()` 返回完整快照的API，仅在主循环/性能热路径中跳过未使用快照；缓存动画片段时长并以二分定位帧；以稳定的相同排序键取最小目标。保留60Hz规则更新，并用高精度帧等待稳定帧间隔。
