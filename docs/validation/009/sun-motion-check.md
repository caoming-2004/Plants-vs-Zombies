# 阳光运动与收集验收

结果：通过。天空与关卡表生成的阳光从屏幕上沿起步，用90 tick（1.5秒）缓出落到既有目标；植物产出的阳光从目标上方34像素进入，用30 tick（0.5秒）落下。落地后以3像素振幅、120 tick周期轻柔浮动。位置在每个逻辑 tick 内确定性更新，渲染与 `input.click` 共用同一 snapshot 的 `x/y`。

阳光价值、生成间隔、600 tick存续期和暂停行为未改变；寿命仍从创建 tick 计时。收集事件仍保持旧事件字段形状，短暂圆环反馈从上次已绘制的位置取值，不改回放事件格式。

定向用例确认移动中可点击、暂停冻结、余额只加一次、重复收集无效及到期删除；同批最终 `tests/integration/test_playable_loop.py` 用例通过。
