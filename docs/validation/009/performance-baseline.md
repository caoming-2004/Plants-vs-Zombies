# 性能与阳光基线（修改前）

## 进入画面

最近一次可复核的真实窗口样本来自 `docs/validation/007/start-transition.md`：注入开始按钮事件，采集10次点击到首个对局画面，结果为 47.02、52.70、77.43、51.71、53.75、55.04、52.99、47.46、65.84、50.42 ms。该测量使用真实窗口与运行时单调时钟；首轮菜单绘制后注入事件，未覆盖人工鼠标误差。

## 标准场景

最近的标准窗口样本来自 `docs/validation/008/window-benchmark.json`：10.007秒、62.26 FPS、P95 16.03 ms、>33 ms 帧1次（最长连续1帧），最长帧间隔53.976 ms。单个长帧未在该报告中归因；绘制器最大分段耗时45.938 ms，其他帧间隔接近60 Hz。此基线对应狗狗卡通植物与敌方皮肤。

## 阳光

原有 `SunPickup` 创建后一直使用固定 `x/y`；渲染器将太阳图像画在这些坐标，`input.click` 亦以相同坐标命中。点击、暂停和寿命使用逻辑实体状态，但尚无落地轨迹或落地后浮动。
