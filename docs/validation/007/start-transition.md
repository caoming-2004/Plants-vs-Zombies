# 开始界面切换

现有 `AppearanceController.on_restart()` 每次开始都会强制重载默认和选定皮肤图集，造成点击后同步磁盘读取。现改为使用 `Catalog` 缓存，仅在 manifest 或 atlas 的文件大小/修改时间变化时重载。点击开始后先绘制按钮高亮边框并显示，再处理重置与对局画面。

在真实显示窗口中注入开始按钮鼠标按下事件，测量事件进入循环到反馈帧、首个对局帧的时长，连续十次（毫秒）：

| 次数 | 反馈 | 对局画面 |
|---:|---:|---:|
| 1 | 1.11 | 47.02 |
| 2 | 0.62 | 52.70 |
| 3 | 0.62 | 77.43 |
| 4 | 0.60 | 51.71 |
| 5 | 0.59 | 53.75 |
| 6 | 0.34 | 55.04 |
| 7 | 0.64 | 52.99 |
| 8 | 0.57 | 47.46 |
| 9 | 0.40 | 65.84 |
| 10 | 0.57 | 50.42 |

每次反馈小于 100 ms、对局画面小于 1 秒；第 1 次截图见 `start-after-click.png`。测试采用注入事件，未测真实人手操作或胜负后的重开切换时长。测量脚本：`tools/measure_start_transition_007.py`。
