# Feature Specification: 第一版背景与角色画质、流畅度恢复

**Feature Branch**: `006-first-version-visual-quality`  
**Created**: 2026-10-27  
**Status**: Draft  
**Input**: 用户要求在当前基础上，以第一版游戏的背景构图为基准提升背景和狗狗画质，并恢复第一版流畅的植物与僵尸动作帧率。

## User Scenarios & Testing

### User Story 1 - 保留第一版构图并提升背景清晰度 (Priority: P1)

玩家进入游戏后仍看到第一版熟悉的房屋、草坪、道路和种植区布局，但背景细节更清楚，不因窗口尺寸放大而出现明显模糊或锯齿。

**Why this priority**: 背景占据大部分画面；用户明确要求回到第一版背景并提高画质，而非改换游戏场景。

**Independent Test**: 将第一版与新版相同场景分别以 1050×600、1260×720 和 1920×1080 显示，逐尺寸并排核对房屋、道路、草坪区域、种植格、光照和主要色彩构图。

**Acceptance Scenarios**:

1. **Given** 玩家打开白天关卡，**When** 查看任一目标窗口尺寸，**Then** 房屋、草坪、道路和种植区域的位置与第一版一致，未出现裁切、拉伸或区域错位。
2. **Given** 玩家在窗口中查看放大后的背景细节，**When** 与第一版原图对照，**Then** 新背景显示新增且自然的细节，边缘清楚，没有把低分辨率原图简单放大造成的块状模糊。
3. **Given** 玩家种植、拖放植物或收集阳光，**When** 新背景正在显示，**Then** 行列边界及可交互物仍清楚可辨，原有操作位置不变。

### User Story 2 - 提升狗狗角色素材的清晰度 (Priority: P1)

玩家选择已有的照片版或卡通版狗狗外观时，能辨认各狗身份；游戏动作保持完整，边缘干净，正常游戏尺寸下不会看到明显像素块、彩色毛边或模糊裁切。

**Why this priority**: 狗狗是本项目的主要个性化内容，低清素材会抵消高质量背景带来的改善。

**Independent Test**: 对照片版和卡通版的狗狗卡片、预览、草坪待机及必要动作，在 1050×600、1260×720 和 1920×1080 下检查清晰度、轮廓、身份特征、动作完整性和透明边缘。

**Acceptance Scenarios**:

1. **Given** 玩家在菜单预览或对局查看狗狗角色，**When** 使用照片版或卡通版，**Then** 角色的脸部、毛色和主要标志清楚，身份与选项一致。
2. **Given** 狗狗播放待机、攻击、受击或结束动作，**When** 画面以目标窗口尺寸显示，**Then** 身体不被裁切，帧与帧之间没有明显闪烁、彩色背景残边或低分辨率放大块。
3. **Given** 狗狗角色与植物或相邻格重叠，**When** 检查游戏画面，**Then** 头部及主要身体轮廓清楚，且继续满足既有狗狗尺寸和遮挡要求。

### User Story 3 - 恢复第一版的流畅动作帧率 (Priority: P1)

玩家在打包游戏中看到植物、僵尸和投射物动作连续，帧率遵循第一版约 60 FPS 的节奏，鼠标操作和画面反馈及时。

**Why this priority**: 当前用户仍报告动作卡顿；仅有合成负载的性能测量不能代表实际对局观感。

**Independent Test**: 在用户当前电脑运行第一版基线和新打包版，使用相同窗口尺寸、显示器刷新率和输入步骤，分别运行标准对局和固定压力场景各 60 秒；记录真实显示帧间隔、平均帧率和真人输入至可见反馈延迟。

**Acceptance Scenarios**:

1. **Given** 新版打包游戏运行标准对局，**When** 连续运行 60 秒，**Then** 测得的渲染循环平均帧率至少为 58 FPS 且不低于同条件第一版基线的 97%，P95 帧间隔不超过 18 毫秒，并且没有连续两帧以上超过 33 毫秒的停顿。游戏仍保持第一版的 60 FPS 节奏设定；高于 60 的循环采样值单独记录，不作为卡顿或失败判据。
2. **Given** 固定压力场景运行 60 秒，**When** 植物、僵尸和投射物同时行动，**Then** P95 帧间隔不超过 20 毫秒，且没有连续两帧以上超过 33 毫秒的停顿。
3. **Given** 玩家在实际窗口中拖放、铲除或收集阳光，**When** 测量至少 20 次操作，**Then** 操作正确处理，95% 的可见反馈延迟不超过 100 毫秒。
4. **Given** 第一版和新版运行相同的确定性回放输入，**When** 比较玩法事件和最终状态，**Then** 事件类型及 tick、最终胜负、阳光、击杀数和割草机状态一致；帧率恢复不以跳过玩法更新或动作姿势为代价。

### Edge Cases

- 第一版原图在小窗口显示清晰、但在 1920×1080 放大时不足以支撑细节时，应在保留其构图的前提下补绘或重绘细节，不能将不匹配的整幅网络背景直接替换进来。
- 外部背景素材即使标有宽松授权，若作者、许可或使用条件无法核实，则不得纳入发行版。
- 窗口缩放、切换尺寸、暂停和恢复后，背景不得错位，游戏输入坐标与种植区不得改变。
- 用户提供的照片、卡通素材可能有不同源分辨率、裁切和透明边缘；不得通过混用其他狗的身份素材掩盖缺陷。
- 刷新率低于 60 Hz、窗口被操作系统遮挡或机器负载异常时，必须记录环境并区分外部限制与游戏帧率退化；不得将模拟渲染或合成事件当作真实窗口和真人输入验收。
- 第一版性能基线或确定性回放基准无法采集/读取时，对应比较项必须标记为未完成（INCONCLUSIVE），不得省略比较后直接判定通过。

## Requirements

### Functional Requirements

- **FR-001**: 背景 MUST 以第一版提交 `7305e3d` 中的 `assets/skins/default/ui-background.jpg` 作为构图基准，保留房屋、草坪、道路、种植区的相对位置、视角和整体色彩关系。
- **FR-002**: 背景 MUST 在 1050×600、1260×720 和 1920×1080 显示尺寸下呈现清晰自然的细节；不得仅把第一版低分辨率图像放大作为画质提升。
- **FR-003**: 外部背景或纹理素材 MUST 在许可、作者和来源均可核验且适合第一版构图时使用，离线发行包须包含最终使用的资源和来源/许可记录。
- **FR-004**: 照片版和卡通版狗狗素材 MUST 保持现有角色身份、选肤映射、必要动作与玩法表现，同时改善正常游戏显示尺寸下可见的轮廓、面部/毛色细节及透明边缘质量。
- **FR-005**: 狗狗、植物、僵尸的可见动画 MUST 保持第一版 60 FPS 节奏设定；标准对局的渲染循环平均帧率 MUST 至少为 58 FPS，且不得低于同条件第一版实测值的 97%。采样值高于 60 FPS 时仍须记录，但不得单凭该值判定失败。
- **FR-006**: 游戏 MUST 在用户当前电脑的打包版真实显示窗口中，通过标准和压力场景的帧率、帧间隔及真人输入反馈验收；测量结果须注明设备、刷新率、窗口尺寸、场景负载及测量时长。
- **FR-007**: 标准场景 60 秒的 P95 帧间隔 MUST 不超过 18 毫秒；压力场景 60 秒的 P95 帧间隔 MUST 不超过 20 毫秒；两场景均不得出现连续两帧以上超过 33 毫秒的停顿。
- **FR-008**: 至少 20 次拖放、铲除和阳光收集的实际操作 MUST 正确处理，95% 的操作到可见反馈延迟不超过 100 毫秒。
- **FR-009**: 背景和角色画质改善 MUST 不改变已有种植、阳光、伤害、僵尸推进、暂停、胜负、重新开始、角色映射及角色遮挡验收规则。
- **FR-010**: 游戏 MUST 使用同一确定性回放输入对比第一版和新版；报告必须比较玩法事件类型及 tick、最终胜负、阳光、击杀数和割草机状态，并说明任何差异。

### Key Entities

- **第一版视觉基准**：第一版背景图及同场景画面，用于核对构图、颜色、角色尺寸与显示效果。
- **高清视觉素材**：保持第一版构图的背景细节、狗狗照片版与卡通版动画资源，以及其来源、许可和清晰度验证记录。
- **实机流畅度样本**：用户当前电脑、打包版本、显示刷新率、场景负载、帧间隔和真人输入响应记录。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 第一版与新版在三种指定窗口尺寸下完成同场景原始截图对比；房屋、道路、草坪、种植区布局四项全部一致，背景无可见块状放大、明显模糊或边缘断裂。
- **SC-002**: 两种狗狗外观中所有必要动作均在三种指定窗口尺寸下完成画面检查；角色身份可辨、身体无裁切、透明边缘无明显彩色毛边或块状伪影，并满足既有遮挡上限。
- **SC-003**: 用户当前电脑上的新版打包游戏标准场景渲染循环平均帧率至少为 58 FPS，且不低于同条件第一版基线的 97%；标准场景 P95 帧间隔≤18 毫秒、压力场景 P95≤20 毫秒；两场景均无连续两帧以上大于 33 毫秒。报告同时记录显示器刷新率与实测循环帧率。
- **SC-004**: 至少 20 次真实操作均正确处理，95% 可见反馈延迟≤100 毫秒；报告包含操作类型、窗口和显示刷新率。
- **SC-005**: 使用同一确定性回放分别运行第一版和新版；玩法事件类型及 tick、最终胜负、阳光、击杀数和割草机状态全部一致。

## Assumptions

- “第一版”以项目历史提交 `7305e3d` 的背景素材和游戏节奏作为可复现基准；若旧发行包不可用，可从该提交构建基线版，并在同一台电脑上与新版对比。
- 游戏仍以约 60 FPS 显示上限和 60 Hz 玩法更新为目标；针对更高刷新率显示器，验收以显示帧时间稳定和不改变玩法速度为准。
- 性能工具的 average_fps 是实际显示路径中的渲染循环采样率，不是显示器刷新计数；在 60Hz 显示器上出现略高于60的循环采样值可能来自计时粒度/合成路径，须报告但不作为失败。是否退化以同条件第一版基线比较、P95帧间隔和连续慢帧共同判断。
- 网络素材只作为重绘或细节补充参考，不要求整张背景照搬；风格、布局与现有关卡一致优先于素材来源。
- 狗狗照片版及卡通版选择能力沿用当前功能；本轮聚焦提升它们在游戏实际尺寸下的视觉清晰度和动画呈现质量。

## Background Research

下列联网素材作为可选参考，最终使用前仍需确认下载文件、具体许可文本和构图适配。它们均不能直接替代第一版的完整房屋与道路构图：

- [Grassy Plains Background — OpenGameArt](https://opengameart.org/content/grassy-plains-background)：页面列出作者 Theoden、CC0 许可；可评估其草地/天空绘制细节是否适合用于第一版背景重绘参考。
- [Grass — OpenGameArt](https://opengameart.org/content/grass-9)：页面列出 1024×1024 草地纹理和 CC0 许可；可作为草地区域细节参考。
- [High res animated grass for fixed background — OpenGameArt](https://opengameart.org/node/97785)：页面标注 1920×1080、高分辨率与 CC0，作者说明为分层草地背景组件；可用于构建草地细节，建筑和道路仍须保持第一版布局并单独核对来源。
