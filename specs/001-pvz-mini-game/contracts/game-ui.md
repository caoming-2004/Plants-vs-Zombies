# Game UI Contract

## 屏幕与操作

- 主菜单：开始、玩法说明、外观选择、退出；全中文，外观默认原版。
- 外观选择：植物方与进攻方各自选择default/dogs；显示名称、三种角色预览；无完整皮肤时禁用相应项并说明原因。
- 战斗：顶部左侧两张价格/冷却卡片和铲子；右上固定显示阳光余额、关卡、波次/击杀和暂停；五行十二列草坪、五台割草机。
- 左键优先命中交互控件，再收集可见场上阳光，再处理草坪操作；同次点击只产生一种命令。HUD 点击区域与场上对象不重叠。
- 选卡后左键空格种植，成功后清除选择；失败保留选择并显示中文原因。右键或Esc取消植物/铲子选择。
- 铲子选中后左键已种格立即移除植物，保持铲子选择便于连续操作；空格无效果。
- 暂停遮罩阻止场地交互；继续/退出可操作；恢复时丢弃暂停期间积累的时间。
- 胜负界面：结果、重新开始、返回菜单、退出；禁止底层场地输入。
- 重新开始保留外观并清除选择；返回菜单后可重新选择外观。

## 画布、地图与图层

- 战斗画布为1050×600逻辑像素，初始窗口1260×720；窗口客户区最小为1050×600逻辑像素，不得缩小至该尺寸以下；更大窗口内等比例缩放并居中，输入反向映射到画布，留边点击无效。
- 草坪起点为(105,160)，格子为72×76像素，五行十二列；草坪边界为x=969、y=540。完整十二列必须同屏显示；窗口空间不足时不得通过缩小画布、滚动或缩小单格来容纳，窗口尺寸须保持在受支持下限以上。
- 原菜单美术按原始比例居中显示在扩展画布中，使用边缘填充补足，不拉伸菜单角色或图标。
- 世界绘制顺序：背景/草坪、割草机及植物/僵尸/投射物/场上阳光、顶部HUD及控件、提示和模态遮罩。右上阳光HUD在任何世界图像之后绘制，整个图标/数值区域不得被场上阳光覆盖。
- HUD位置保留于战斗画布的顶部区域；草坪角色与可收集阳光不得绘制到HUD专属矩形中。HUD hit-test先于场上阳光收集和草坪操作。
- 角色脚底锚点固定，死亡表现不占格、不受攻击、不影响结算。
- 默认画面以PC初代经典版对照板验收；中文界面和仅两张卡片属于本项目明确的内容范围。
- 皮肤错误提示可理解且不弹开发堆栈；默认资源不可用时阻止开局，提供缺失文件说明。

## 可验收布局行为

- 所有受支持窗口客户区（至少1050×600逻辑像素）都须显示全部十二列；在最低支持尺寸下使用逻辑画布1:1显示，格子保持72×76逻辑像素且可准确点击，不允许窗口缩小至该下限以下、裁剪或水平滚动。
- 右上HUD前景图层保持高于角色、特效、阳光和装饰；在最密集场景及场上阳光靠近画面右上方时截图核验无遮挡。
- 输入测试分别点击HUD、其边界、场上阳光和草坪，确认优先级唯一，不发生一次点击触发两个命令。
