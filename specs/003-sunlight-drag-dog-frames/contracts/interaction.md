# 游戏界面与鼠标交互契约

本契约描述玩家可见位置与输入结果；不新增外部API。所有位置均使用现有1050×600逻辑画布。

## 阳光余额

- 阳光图标与余额显示在游戏界面左上角，余额值直接反映当前对局资源。
- 阳光面板的共享命中矩形用于输入屏蔽和拖动预览遮挡，不能在其下触发游戏世界点击。
- 面板与草坪上可点取的阳光是两种不同对象；余额面板不拦截有效草坪拾取。
- 左上角面板不得碰到从逻辑x=162开始的首张植物卡，也不得遮挡暂停控件或必要文字。

## 操作语义

| 按下控件 | 释放位置/行为 | 结果 |
|---|---|---|
| 任一植物卡 | 同一卡/短按 | 选择该植物，保留已有点击选卡行为。 |
| 任一植物卡 | 空草坪格 | 同一游戏tick内按序提交植物选择与一次放置；结果由Domain最终校验。 |
| 任一植物卡 | 占格、草坪外、留边或界面控件 | 不放置、不扣费、不点击控件背后的草坪；显示适当的无效反馈。 |
| 铲子 | 铲子按钮/短按 | 选择铲子，保留已有点击铲除操作。 |
| 铲子 | 有植物的草坪格 | 按序提交铲子选择与一次移除；不返还阳光。 |
| 铲子 | 空格、草坪外、留边或界面控件 | 不删除单位、不触发控件下方的场地操作。 |
| 植物卡或铲子拖动 | Esc、右键、窗口失焦、暂停、结束或切换场景 | 立刻清除预览和拖动态；不得延迟执行。 |

## 反馈与规则边界

- 植物预览显示释放格和当前有效/无效状态；资源不足、冷却、占格等原因保持中文可理解。
- 铲子拖动预览需区分有植物目标与空目标，不修改游戏状态。
- 鼠标释放再按当前游戏状态结算；拖动起始时的资源/目标有效状态不构成最终授权。
- 点击和拖放进入相同的Simulation命令规则；素材外观不得影响命令及其结果。
- 窗口缩放/留边沿用现有逻辑坐标转换，黑边位置视为界面外。

## 用户素材接入契约

- 小宝的来源帧只用于`wallnut`；小杜的来源帧只用于`jalapeno`。
- 用户上传文件可为逐帧图或合成图；收到后记录文件及来源摘要，先检查帧序/动作覆盖，再导入既有dogs manifest。
- 动作覆盖、帧速率、循环和定位必须通过既有资源验证；不能用重复图冒充用户源帧。输入不足时报告缺口并停止该角色的素材发布。
