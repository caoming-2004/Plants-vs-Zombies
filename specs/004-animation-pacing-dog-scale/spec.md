# Feature Specification: 动画节奏与小狗显示尺寸调整

**Feature Branch**: `version1`

**Created**: 2026-10-26

**Status**: Draft

**Input**: 用户反馈：植物和僵尸动作帧少但播放过快，显得急促卡顿；小杜火爆辣椒的爆炸显示过快，期望持续1至2秒；小宝体型偏小、动作显示不完整，并希望小杜的图片展示调大。

## Clarifications

### Session 2026-10-26

- Q: 规格目前把每秒12–18个可辨认姿势用于普通循环动作；攻击、受击和死亡动作只要求完整播放。你希望单次动作也采用这个姿势速率吗？ → A: 所有动作都按12–18个姿势/秒播放，玩法结算速度不变。
- Q: 小杜爆炸素材有35个原始姿势，按12–18姿势/秒完整播放至少约需1.95秒；如何处理时长与姿势速率冲突？ → A: 爆炸设为2秒，完整播放35个源姿势，约17.5姿势/秒。

## User Scenarios & Testing

### User Story 1 - 让植物和僵尸动作节奏自然 (Priority: P1)

玩家观察植物待机、攻击、受击，以及僵尸行走、啃咬和受击时，能看清每个动作的过程，不会因有限的姿势快速循环而显得闪动、急促或卡顿。游戏画面和玩法时钟仍稳定运行，动画节奏调整不改变移动、攻击或结算速度。

**Why this priority**: 动作观感是持续对局中最常见的视觉体验；降低动作过快造成的闪动，同时保持实际玩法节奏，可直接改善试玩感受。

**Independent Test**: 在固定关卡中分别观察植物和僵尸的待机/移动、攻击/啃咬、受击和结束动作；记录动作姿势切换速率、循环时长，并比较调整前后的模拟位置、攻击和胜负状态。

**Acceptance Scenarios**:

1. **Given** 游戏以正常速度运行，**When** 植物或僵尸播放待机、移动、攻击、啃咬、受击或死亡动作，**Then** 关键姿势切换保持在每秒12至18个可辨认姿势，单个姿势不会因60Hz画面刷新而被快速跳过。
2. **Given** 僵尸正在草坪上推进或攻击，**When** 所有动作姿势按12至18个/秒播放，**Then** 僵尸推进速度、攻击间隔、伤害和胜负时序仍与调整前一致。
3. **Given** 游戏暂停或恢复，**When** 动作动画更新，**Then** 暂停时动作停止，恢复后从当前动作进度继续，不出现突然跳帧或重新开始整个循环。

---

### User Story 2 - 看清小杜的整行爆炸动作 (Priority: P1)

玩家种下火爆辣椒后，能完整看见小杜点燃、喷火及火焰消退的过程。爆炸效果持续足够时间让玩家辨认，同时整行清除规则仍只结算一次。

**Why this priority**: 爆炸是火爆辣椒的核心反馈；当前效果结束过快，使角色动作和整行清除不易看清。

**Independent Test**: 在同一行放置至少两只僵尸后种下火爆辣椒，计时从种植成功/清行效果启动到火焰完全消失，并核对僵尸只被清除一次、随后游戏继续正常运行。

**Acceptance Scenarios**:

1. **Given** 火爆辣椒在有效草坪格种植成功，**When** 整行清除效果启动，**Then** 小杜的点燃/喷火/消退整体可见时长为2.0秒，允许误差±0.1秒，并完整展示35个源姿势。
2. **Given** 爆炸效果正在播放，**When** 同一行有多个僵尸，**Then** 现存僵尸仅被清除一次；效果延长不会重复伤害、重复结算或阻塞后续波次。
3. **Given** 爆炸播放期间暂停或进入结算界面，**When** 游戏状态变化，**Then** 效果进度服从现有暂停/场景规则，不在新对局中残留。

---

### User Story 3 - 完整显示并放大小宝和小杜 (Priority: P1)

玩家在植物卡、选肤预览和草坪中能更清楚地看到小宝与小杜。两只狗狗的全身和适用动作均显示完整，脚底位置稳定，不会被卡片边界裁切、越出草坪或遮住相邻格的主要角色。

**Why this priority**: 用户提供的小狗素材是这两个植物角色的辨识重点；当前尺寸偏小或构图裁切会削弱角色辨识和动作信息。

**Independent Test**: 在默认及dogs外观下检查两种植物的卡片、预览、草坪角色，以及小宝站立/受击/卧倒和小杜种植/喷火/恢复动作；对比当前版本的角色可见像素边界及脚底锚点。

**Acceptance Scenarios**:

1. **Given** 玩家选择dogs植物外观，**When** 查看小宝和小杜的卡片、预览与草坪角色，**Then** 其草坪可见角色高度较当前版本至少增加15%，且每个动作主体均完整显示。
2. **Given** 小宝或小杜播放任一动作，**When** 姿势变化导致外接框不同，**Then** 脚底锚点保持稳定，图像不被来源帧边缘、卡片可视区或草坪边界裁掉。
3. **Given** 小宝和小杜放大后处于相邻行或相邻格，**When** 两个角色同时显示，**Then** 角色仍位于各自目标格，且不会遮挡相邻角色的主要身体部分。
4. **Given** 玩家切换经典/dogs外观，**When** 相同关卡使用同一组输入，**Then** 植物数值、动作推进和战斗结果完全一致。

### Edge Cases

- 增大角色后，最高/最宽姿势不得越出逻辑画布，也不得被UI遮挡或被卡片预览容器切掉。
- 不同动作clip帧数不同、循环或单次播放时，姿势速率都须保持每秒12–18个可辨认姿势；单次动作还须完整表现其动作语义。
- 帧率不稳定、窗口缩放、暂停/恢复和对局重开不得导致动作计时累计或爆炸时长变化。
- 爆炸期间游戏结束、暂停或快速重开时，旧清行特效不得进入下一局。
- 外观素材缺失或损坏时继续沿用既有整套外观回退规则。

## Requirements

### Functional Requirements

- **FR-001**: 游戏 MUST 保持60Hz模拟与60FPS目标画面刷新；动画姿势播放速度独立于游戏规则时钟及窗口绘制频率。
- **FR-002**: 植物和僵尸所有动作（包括循环及攻击、啃咬、受击、死亡等单次动作）的可辨认关键姿势 MUST 按每秒12至18个姿势播放；源姿势须按序可见，不得因渲染帧率较高而跳过。
- **FR-003**: 所有动作 MUST 按语义完整播放；减慢姿势播放不得改变实际攻击、移动、伤害、冷却和死亡结算时间。
- **FR-004**: 火爆辣椒整行爆炸视觉 MUST 从清行效果启动到完全消退持续2.0秒±0.1秒，并按序完整展示35个源姿势（约17.5姿势/秒）。
- **FR-005**: 爆炸时长调整 MUST 只改变表现持续时间，不得增加整行清除的结算次数或延迟后续规则推进。
- **FR-006**: dogs外观中的小宝和小杜草坪显示高度 MUST 较当前版本增加至少15%，并保证必需clip所有源姿势主体完整可见。
- **FR-007**: 放大后两只角色 MUST 保持脚底/落点稳定，不得裁切卡片、预览和草坪显示区域或遮挡相邻角色主要轮廓。
- **FR-008**: 角色显示尺寸和动画节奏 MUST 仅影响表现，不改变default/dogs外观下的玩法状态、资源、伤害、位置推进或胜负结果。
- **FR-009**: 暂停、恢复、对局结束和重新开始 MUST 按既有生命周期正确冻结、清理或重置动画与爆炸进度。

### Key Entities

- **动作姿势节奏**：植物或僵尸动作中可辨认姿势之间的显示频率与各姿势保持时间。
- **整行爆炸效果**：火爆辣椒触发的一次性表现阶段，从启动、喷火到火焰完全消退。
- **角色可见边界**：小宝或小杜在卡片、预览、草坪中实际显示的全身边界、脚底锚点和目标格归属。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 植物和僵尸所有循环及单次动作实测关键姿势频率为12–18个/秒；模拟时钟和画面更新目标维持60Hz/60FPS。
- **SC-002**: 对固定关卡和确定性输入保存修改前模拟基准；修改后逐项比较事件及tick、僵尸位置/推进、攻击间隔与伤害、阳光变化、击杀和最终胜负，结果与基准完全一致。
- **SC-003**: 火爆辣椒清行特效从触发到完全消退为1.9–2.1秒，35个源姿势按序完整播放；同一动作中的整行规则结算仅发生一次。
- **SC-004**: 小宝和小杜草坪角色可见高度都比当前版本至少提高15%；100%必需动作clip抽查中无身体主体被裁切，脚底锚点变化不超过2个逻辑像素。
- **SC-005**: 在1050×600、1260×720、1920×1080逻辑呈现窗口尺寸下，角色无窗口边界裁切；相邻格测试中不遮盖相邻角色的主体。
- **SC-006**: default与dogs两种外观完成待机/移动、攻击、受击、结束动作，暂停/恢复/重开和完整核心循环回归，玩法结果保持一致。

## Assumptions

- 本轮“帧率”指动画姿势切换/播放速度，不指屏幕刷新或模拟速度；游戏继续以60Hz模拟并以60FPS为绘制目标。
- 用户已明确选择2.0秒完整播放小杜35个源姿势（约17.5姿势/秒），满足动作姿势速率和完整素材展示要求。
- “放大图片”同时适用于小宝和小杜的草坪表现；卡片和预览优先完整显示主体，按容器可用空间同比调整。
- 当前狗狗源图及default角色资源继续复用，素材重绘和新增音效不在本Feature范围内。
- 旧的至少24个不同可见姿势/秒普适门槛由本Feature针对动画播放观感的12–18姿势/秒门槛取代；60Hz画面刷新和游戏规则时钟不变。

## Pose Rate Measurement

- 姿势率以皮肤manifest动作clip中的可见姿势计数；将帧解码为RGBA后，像素内容完全相同的帧视为同一姿势，clip中唯一姿势数记为pose_count。姿势率为pose_count × assets/config/balance.json中的tick_hz / clip总duration_ticks；tick_hz当前为60。
- 自动计数是可复测的代理指标；导出的动作接触表还须人工确认差异确实体现动作姿态，而非仅有无关像素变化。
- 小杜清行是明确例外：按provenance指定的35个源姿势计数和播放，生成的中间帧不计入这35个源姿势；清行clip只含这35个姿势。
