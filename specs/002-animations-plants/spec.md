# Feature Specification: 动画、操作与植物扩展

**Feature Branch**: `version1`

**Created**: 2026-10-26

**Status**: Draft

**Input**: 用户要求提高游戏画质及植物、僵尸（含狗狗外观）的动画帧率；优化拖动和放置的流畅感，可加入音效；新增坚果墙（小宝）、火爆辣椒（小杜），并将豌豆射手狗狗外观改为黄黄。

## Clarifications

### Session 2026-10-26

- Q: 火爆辣椒种下后，你希望它如何处理本行当前存在的僵尸？这决定范围攻击规则和胜利结算时机。 → A: 立即消灭本行所有现存僵尸。
- Q: 在画面以60帧/秒更新时，植物和僵尸的关键动作每秒至少应展示多少个不同姿势？这会决定需要制作的动画素材量和流畅度验收门槛。 → A: 每秒至少24个不同姿势。
- Q: 这轮功能是否要把音效作为必交内容，还是先集中完成画质、拖放和新增植物？这会影响素材准备、发行包内容和验收范围。 → A: 本轮不做音效，之后单独规划。

## User Scenarios & Testing

### User Story 1 - 拖动卡片并准确种植 (Priority: P1)

玩家从卡槽按住植物卡片，拖到草坪目标格并松开，看到随指针移动的半透明植物预览和目标格反馈；放开后植物落在对应格子。操作失败时能看懂原因并继续拖动或取消。

**Why this priority**: 种植是核心循环的主要操作，拖动反馈能让初次游玩的玩家更容易理解卡片、目标位置与种植结果。

**Independent Test**: 在四张卡都可用的对局中，分别拖动到空格、已占格、卡片冷却中或阳光不足的目标；检查落点、提示、资源和冷却，并用右键/Esc取消一次拖动。

**Acceptance Scenarios**:

1. **Given** 植物卡片可用且资源充足，**When** 玩家将卡片拖到空草坪格并松开，**Then** 预览吸附到该格，植物恰好种在该格，资源扣除一次且卡片进入冷却。
2. **Given** 玩家正在拖动植物卡片，**When** 指针经过有效格、占用格、草坪外或HUD，**Then** 目标反馈清楚区分可放置和不可放置位置，且植物预览不会遮挡卡片价格、阳光余额或拖动目标。
3. **Given** 目标格已占用、阳光不足或卡片冷却中，**When** 玩家松开卡片，**Then** 不扣除资源、不改变已有植物或冷却，并显示对应中文原因。
4. **Given** 玩家正在拖动卡片，**When** 按右键或Esc，**Then** 拖动立即取消且不产生种植、扣费或残留预览；暂停、结算或切换场景时也不会保留过期拖动态。
5. **Given** 玩家将卡片拖到草坪外或其他界面控件上松开，**When** 输入结束，**Then** 不会误种到最近格、不触发该控件后方的场地操作，且卡片回到可用状态。

### User Story 2 - 使用新增植物改变防线 (Priority: P1)

玩家在同一关卡中选择向日葵、豌豆射手、坚果墙或火爆辣椒。坚果墙以耐久阻挡同排僵尸；火爆辣椒种下后对同排僵尸发动一次性范围攻击。卡片、预览和场上外观展示相应小狗角色。

**Why this priority**: 两种新增植物提供耐久防守与紧急清线选择，扩展既有收集阳光、布置和抵御僵尸的核心循环。

**Independent Test**: 在固定关卡中分别放置坚果墙和火爆辣椒，检查卡片状态、资源与冷却、僵尸受影响的行、植物生命和胜负；随后以相同输入运行四种植物外观组合，核对规则结果一致。

**Acceptance Scenarios**:

1. **Given** 卡片可用且资源充足，**When** 玩家放置坚果墙，**Then** 场上出现坚果墙“小宝”外观，该植物不攻击或产出资源，接触它的僵尸会停下并啃咬，坚果墙生命耗尽后僵尸恢复前进。
2. **Given** 同一行有一只或多只僵尸，**When** 玩家放置火爆辣椒，**Then** 出现火爆辣椒“小杜”外观及一次性火焰表现，并立即消灭该行所有现存僵尸；其他行僵尸不受影响，后续进入该行的僵尸不被追溯攻击。
3. **Given** 选择坚果墙或火爆辣椒，**When** 玩家尝试在占用格、资源不足或冷却期间种植，**Then** 种植按统一规则失败，资源、冷却、格子及已有单位均保持不变。
4. **Given** 玩家切换默认外观或小狗外观，**When** 开始相同关卡并执行相同输入，**Then** 新植物的价格、生命、攻击范围、伤害、冷却及战斗结算不因外观而改变。
5. **Given** 用户查看卡槽或拖动预览，**When** 查看四种植物，**Then** 卡片、名称、职责提示、价格、冷却与场上角色映射一致，并且四张卡在支持画面内均可见和操作。

### User Story 3 - 看清更细致、更流畅的角色动作 (Priority: P2)

玩家在不同窗口大小和双方外观组合中观察植物、僵尸及小狗皮肤，能够辨认角色职责和状态；待机、移动、攻击、受击、死亡、产出与爆发效果切换自然。

**Why this priority**: 画面清晰度和动作流畅度让新增植物、战斗状态与角色个性容易辨认，并提升现有角色体验。

**Independent Test**: 在默认/默认、植物狗狗/僵尸默认、植物默认/僵尸狗狗、双方狗狗四种组合中重复播放各角色的适用动作；检查原生显示及较大窗口、目标帧率、锚点、循环接缝和状态切换。

**Acceptance Scenarios**:

1. **Given** 游戏以1050×600、1260×720或1920×1080显示，**When** 检查四种外观组合的截图和动画循环，**Then** 非预期帧裁切为0、循环首尾锚点偏差≤2逻辑像素、卡片/HUD/交互区域相互遮挡为0，且无闪烁或透明边缘异常；每种组合与尺寸均记录PASS/FAIL/NOT_RUN。
2. **Given** 游戏在60Hz显示设备上运行，**When** 观察植物、僵尸及两方小狗的重复动作，**Then** 画面更新目标为每秒60帧，关键动作循环具备至少每秒24个不同可见姿态，不出现由更新不足导致的明显跳帧。
3. **Given** 角色由待机切换到攻击、啃咬、受击或死亡，**When** 动作播放，**Then** 朝向、脚底位置和大小保持合理连续；可见发射、啃咬和火焰时刻与实际事件相符。
4. **Given** 处于四种外观组合中的任一种，**When** 固定场景和输入运行，**Then** 植物与僵尸生命、资源、伤害、移动、攻击顺序和胜负结果一致。

### Edge Cases

- 拖动过程中窗口失焦、暂停、结束或返回菜单时，拖动状态应清除，恢复后不得自动种植。
- 拖动期间资源因其他游戏事件减少至不足，松开时按松开时的权威状态重新校验，不允许负资源或重复扣费。
- 同一tick触发火爆辣椒与僵尸啃咬、失败或胜利时，遵循既有稳定结算顺序；火焰只结算一次。
- 火爆辣椒作用行为空时仍按一次成功种植处理，但不得产生无目标的重复伤害或延迟伤害。
- 火爆辣椒种在空行时仍是一次成功种植：扣费并开始冷却，只播放一次完整表现，不创建持续植物，也不产生僵尸击杀事件。
- 同一行有多只僵尸、僵尸处于受击或死亡表现、或生成波次尚未结束时，范围攻击只影响生效时刻仍存活且已经进入关卡的僵尸。
- 新皮肤缺少任一角色或动作时，保持既有按阵营整套回退默认皮肤的行为并显示中文提示。

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 允许玩家按住任一植物卡片并拖至草坪目标格后释放，以现有种植规则校验并执行一次放置。
- **FR-002**: 拖动过程中系统 MUST 显示随指针移动的角色预览、目标格和有效/无效放置状态；放开到非草坪位置、取消、失焦、暂停或切换场景均不得产生放置。
- **FR-003**: 放置成功时系统 MUST 仅扣费一次、占用对应格并开始对应冷却；放置失败时 MUST 保持资源、占格与冷却不变并说明失败原因。
- **FR-004**: 系统 MUST 保留现有点击选卡再点击草坪的种植方式，并支持拖动操作；任一输入方式均不得绕开同一套种植规则。
- **FR-005**: 系统 MUST 提供四张同时可见的卡片：向日葵、豌豆射手、坚果墙和火爆辣椒；卡片显示名称、价格、冷却及可辨认的角色图像。
- **FR-006**: 坚果墙 MUST 作为仅防御植物拥有独立配置的价格、生命值和冷却；不产阳光、不发射攻击；同排僵尸接触后攻击该植物，死亡后恢复前进。
- **FR-007**: 火爆辣椒 MUST 作为一次性植物拥有独立配置的价格和冷却；成功种植时立即消灭同排所有现存存活僵尸，并播放符合攻击方向的完整爆发表现；不得影响其他行或之后才进入该行的僵尸。即使该行为空也算成功种植，须扣费并开始冷却、播放一次表现，不产生击杀事件或持久植物。
- **FR-008**: 两种新增植物的卡片、预览、名称、场上角色、动作、方向和职责提示 MUST 对应一致；缺失皮肤动作须遵循既有整套默认外观回退规则。
- **FR-009**: 植物狗狗外观 MUST 将豌豆射手从嗷嗷嗷改为黄黄；坚果墙使用小宝，火爆辣椒使用小杜。既有向日葵“被窝”和僵尸“嗷嗷嗷”映射保持不变。
- **FR-010**: 四种植物和所有僵尸在默认与小狗外观下 MUST 提供适用的待机、移动、攻击/职责动作、受击和死亡表现；关键动作每秒至少包含24个不同可见姿态，全部角色状态更新目标为每秒60次。
- **FR-011**: 在1050×600、1260×720和1920×1080受支持窗口下，角色、UI和效果 MUST 通过可复查的视觉检查：非预期帧裁切为0，循环首尾锚点偏差不超过2个逻辑像素，卡片/HUD/交互区域互相遮挡为0；四种外观组合均须记录检查结果。不得出现闪烁或透明边缘异常。
- **FR-012**: 在60Hz显示设备的常规场景中，系统 MUST 以每秒60帧为画面更新目标；在本规格SC-007定义的压力场景中，从输入事件注入到首个可见预览的响应P95 MUST 不超过50ms，20次操作中丢失或重复命令为0；玩法时间或命中结果不得因外观组合改变。
- **FR-013**: 关键角色资源 MUST 随发行包提供，首次游玩不要求联网下载或手动安装。
- **FR-014**: 更新植物、渲染或输入 MUST 保持阳光收集、现有种植、战斗、铲子、割草机、暂停、胜负、重开与两方独立换肤可运行。
- **FR-015**: 新植物的平衡数值 MUST 可被集中调整和验证；皮肤与动画 MUST 不改变价格、生命、冷却、攻击范围、伤害、时序或胜负规则。

### Key Entities

- **植物类型**：向日葵、豌豆射手、坚果墙、火爆辣椒及其卡片、职责、价格、生命、冷却和攻击/产出参数。
- **拖动中的卡片**：所选植物、当前目标格、目标有效性及可取消状态；仅在用户拖动期间存在，不代表已种植单位。
- **皮肤角色映射**：植物/僵尸外观模式与具体角色形象名称，包括被窝、黄黄、小宝、小杜和嗷嗷嗷。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 在20次预设拖放操作中，有效目标全部放置到指针释放所在格；无效位置与取消操作均有0次扣费、误放或双重操作。
- **SC-002**: 坚果墙在同排接触时能阻挡并承受攻击，生命耗尽后僵尸继续前进；火爆辣椒每次仅结算一次并立即消灭同排现存僵尸，对其他行和之后进入该行的僵尸造成0次影响。
- **SC-003**: 四种卡片均能在同一受支持画面内辨识和操作；两种外观模式下卡片、预览和实际植物映射一致。
- **SC-004**: 在记录配置的60Hz Windows测试设备上连续测量60秒，常规场景平均画面更新不低于58FPS，95百分位帧间隔不高于25ms；角色动画状态每秒更新至少60次，关键循环可见的不同姿态不少于24帧/秒。压力场景下输入事件至首个可见预览的P95不高于50ms，且20次试验零丢失、零重复命令。
- **SC-005**: 在四种植物/僵尸外观组合及相同输入下，对局资源、单位状态、命中事件与胜负结果完全一致。
- **SC-006**: 完成新功能后，既有核心闭环和铲子、割草机、暂停、胜负、重开与选肤回归检查全部通过。
- **SC-007**: 在tools/benchmark.py定义的固定压力场景（1050×600、45株植物、30只僵尸、100枚投射物、20个阳光）下连续测量60秒，平均画面更新不低于55FPS，95百分位帧间隔不高于33ms；记录硬件与显示信息，SDL dummy结果不能代替Windows实机结果。

## Assumptions

- 本特性基于现有 Windows 桌面游戏、五行十二列地图、1050×600逻辑客户区和菜单换肤流程，继续支持默认/小狗两类外观。
- “豌豆射手改为黄黄”指仅替换植物方豌豆射手的小狗角色；既有僵尸方嗷嗷嗷、向日葵被窝映射维持原样。坚果墙对应小宝，火爆辣椒对应小杜。
- 新增植物仅包含本次明确提出的坚果墙和火爆辣椒；更多植物留待后续特性。
- 火爆辣椒种下后立即消灭本行所有现存僵尸；其价格和冷却由后续方案根据现有小型关卡配置确定。
- 本特性不加入音效或背景音乐；音效作为独立后续特性规划。
- 画质和帧率验收在记录了硬件、显示刷新率、窗口尺寸及场景负载的标准 Windows 测试环境执行；不承诺超出设备能力的刷新率。
- 角色素材须记录来源与许可，并随完整解压发行目录分发；音效素材属于后续独立特性。
